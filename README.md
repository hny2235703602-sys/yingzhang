# 映章 · 小说动漫工作台

依据 `../设计` 的业务方案、工程约束与绿白页面原型实现。第一版完成**章节 → 本章分析 → 改编大纲 → 场景分镜与提示词 → 复核 → 文本预览/导出**，暂不提交视频任务。

## 安装与启动

要求 Python 3.11、uv。环境独立于 ComfyUI。

```bash
cd /Users/apple/ComfyUI/Project
uv sync --frozen
export NOVEL_LLM_API_KEY='你的实际密钥'
uv run python start.py
```

打开 http://127.0.0.1:8501 。启动器先执行 Alembic 迁移，再启动一个独立文本执行器与 Streamlit；页面刷新不会重复启动执行器。退出启动器会停止子进程。依赖仅在显式安装时获取，不在运行时自动安装。

Windows PowerShell：

```powershell
cd 你的项目目录
uv sync --frozen
$env:NOVEL_LLM_API_KEY='你的实际密钥'
uv run python start.py
```

启动后进入「模型与工作流」填写实际供应商、API Base URL（通常以 `/v1` 结尾）、模型 ID，密钥环境变量名填 `NOVEL_LLM_API_KEY`。保存配置后选择当前配置，点击显式连接测试会发送一条很小的真实请求。支持 OpenAI 兼容 Chat Completions 和 Responses；未适配厂商原生协议。不根据模型列表宣称生成可用。

密钥只从执行进程环境读取，不写数据库、检查点、日志或导出。修改终端环境后需重新启动应用与执行器。配置中不能填写真实密钥。`.env.example` 是说明示例，应用不自动加载 `.env`。

## 使用

1. 在侧栏创建作品，导入或粘贴章节，填写可选前情，保存章节。
2. 选择已保存模型配置、画风、画幅与改编偏好，提交文本改编。
3. 「文本任务」查看阶段、错误与更新时间，可在阶段边界暂停、继续，失败后显式重试。已保存的成功阶段/场景不重复生成；有意重新改写创建新运行，保留旧结果。
4. 查看大纲、本章人物关系与存疑项；在分镜工作台按场景筛选、分页、修改提示词并保存新结果版本，下载 JSON 或 Markdown。
5. 将采用的角色视觉资料存入当前作品，后续章节复用。已创建运行保存资料快照，不自动替换旧分镜；修改资料后需有意创建新运行采用新版本。

镜头数按剧情决定，无固定章级时长；5秒为分镜设计参考，不是已适配视频模型的保证。视频提示词是语义草案，台词/文字叠加需求单独展示，不承诺声音和字幕产物。语义复核没有发现问题也不能保证剧情完全准确，需人工阅读效果。

## 本地模型与 ComfyUI

LM Studio 使用相同模型配置和数据契约。填写目标电脑实际服务地址（如 `http://目标IP:1234/v1`）与模型 ID；服务未启用认证时密钥环境变量名可留空，启用认证时填写对应变量名。本机 localhost 不代表另一台电脑。

ComfyUI 配置入口、集成目录和镜头数据契约已保留，当前视频提交明确禁用。获得已跑通的 API 工作流后再实现节点映射与执行核对，不编造节点、帧数和成功状态。

## 数据与恢复

默认 `data/studio.db` 为 SQLAlchemy/SQLite 业务数据，`data/checkpoints.db` 为 LangGraph 官方 SQLite 检查点。业务库仅通过 Alembic 迁移创建与升级。数据目录可用 `YINGZHANG_DATA_DIR` 设置为本地绝对路径；升级已有数据前备份，SQLite在线备份使用 `sqlite3.Connection.backup`，不能在写入时只复制主文件。

独立执行器使用数据库原子领取与租约心跳，多开执行器仍只领取一条运行。执行器失联且租约过期后转为 unknown，需人工核对后点击重试；最后一次未保存调用可能再次计费。暂停只在下一次模型调用前生效，当前调用会先保存结果。网络超时不自动重发，限流/暂时性服务错误在配置预算内重试。

原文按段落编号，长章节分段提取，再按场景拆镜和审核。上下文使用保守字符预算，并拒绝超限阶段，避免静默截断正文；极长单段或全章合并超限时需要增大实际支持的上下文预算或缩小章节。当前不实现无限长文本的递归压缩。
