# 映章 · 小说动漫工作台

依据 `../设计` 的业务方案、工程约束与绿白页面原型实现。第一版完成**章节 → 本章分析 → 改编大纲 → 场景分镜与提示词 → 复核 → 文本预览/导出**，暂不提交视频任务。

## 安装与启动

要求 Python 3.11、uv。环境独立于 ComfyUI。

在项目目录执行：

```bash
cd 你的项目目录
uv sync --frozen
uv run python start.py
```

Windows PowerShell：

```powershell
cd 你的项目目录
uv sync --frozen
uv run python start.py
```

在运行 `start.py` 的那台电脑上打开 http://127.0.0.1:8501 。启动器先执行 Alembic 迁移，再启动一个独立文本执行器与当前网页界面。页面刷新不会重复启动执行器。退出启动器会停止子进程。依赖仅在显式安装时获取，不在运行时自动安装。

从另一台电脑打开云端工作台时，浏览器地址是 http://124.223.189.242:8501 。步骤见 [CLOUD.md](CLOUD.md)。

启动后进入「模型配置」的「文本模型配置」，填写 API 地址、模型名称和 API Key，然后保存。文本模型用于章节分析、大纲、分镜和复核。提示词在「提示词配置」中修改，只作用于之后新提交的任务。支持 OpenAI 兼容 Chat Completions。

「生图模型配置」可选择 OpenAI 兼容图片生成 API，或本机 FLUX.2（mflux）。本机模式填写 `mflux-generate-flux2` 可执行文件路径、模型 ID 与基础模型，不需要 API Key；默认预填当前 FLUX.2-klein-4B Q8 下载位置。生成时使用 1024×1024、4 步和低内存模式，超时可按本机速度调整。保存后进入「图像创作」，点击小说封面，选择章节与分镜，生成 1–4 张镜头候选图；采用后作为该镜头的参考画面展示在总览。OpenAI 兼容服务须返回 Base64 PNG/JPEG；URL 响应当前不支持。

模型配置通过顶部横向分页切换生图和文本模型。提示词配置同样分为「图像创作配置」「分镜拆解配置」「视频制作配置」三页，分别保存。图像创作配置统一维护图片风格、应用场景、构图偏好和画面限制，人物、环境与镜头描述由分镜拆解单独提供。生成前可查看最终提示词并填写本次补充要求。已保存的自定义配置保留；旧的单人角色设定提示词可在该页修改为镜头画面用途。分镜拆解保留分析、大纲、分镜、复核四阶段。视频提示词可保存，视频生成服务尚未接入。

「总览」位于「分镜拆解」上方，展示同一作品封面库。打开作品后按章节查看分镜、参考图、视频三列，分镜来自本章最近一版已有镜头的执行结果。参考图展示图像创作中已采用的镜头画面，也保留已关联的角色参考图；尚无采用画面或最终视频时显示待生成。

「图像创作」与「视频制作」都以只读小说封面库作为入口，作品管理在「分镜拆解」中进行。图像工作台按章节、分镜组织；人物与环境描述来自该版分镜，旧结果从人物分析、视觉资料快照及场景大纲补足。新分镜会单独产出 `character_prompt` 和 `environment_prompt`。图片保存实际提示词、模型及分镜内容指纹，分镜内容变化后旧图片不会自动绑定到新版。视频工作台暂未开放。新增数据表通过启动时的 Alembic `0003` 迁移创建。

密钥从模型配置写入执行器可读的存储，不写入检查点、日志或导出。修改已保存的密钥后，下一次任务使用新配置。`.env.example` 是说明示例，应用不自动加载 `.env`。

## 使用

1. 在首页新建作品，进入分镜拆解后粘贴章节，填写可选前情，保存章节。
2. 从章节原文进入「本章分析与角色资料」，点击生成。每次只执行当前阶段，完成后检查结果并点击「确认本阶段结果」。
3. 确认后手动生成改编大纲，再确认并生成分镜；复核也需要单独点击执行。右侧显示当前阶段、错误和保存进度，失败重试只补做当前阶段未完成部分，不自动进入下一阶段。
   也可点击右侧连线上的圆点选择步骤，绿色表示已选，再点击「启动」。单选只执行一步，连续多选按顺序执行所选步骤，中途逐步保存，结束后统一检查确认；前置步骤需已确认或一并勾选。失败后「继续未完成部分」跳过已保存成果，接着执行本次选择的剩余步骤。执行中的圆点显示旋转高亮边框。
4. 分析和大纲可展开编辑器，修改结构化 JSON 后保存为新版本并重新确认。上游修改或重新生成后，历史下游结果仍保留，并标记依据已更新；需重新生成后才能继续使用。在分镜工作台按场景筛选、分页并下载 JSON 或 Markdown。
5. 将采用的角色视觉资料存入当前作品，后续章节复用。已创建运行保存资料快照，不自动替换旧分镜；修改资料后需有意创建新运行采用新版本。

镜头数按剧情决定，无固定章级时长；5秒为分镜设计参考，不是已适配视频模型的保证。视频提示词是语义草案，台词/文字叠加需求单独展示，不承诺声音和字幕产物。语义复核没有发现问题也不能保证剧情完全准确，需人工阅读效果。

## 本地模型与 ComfyUI

LM Studio 使用相同模型配置和数据契约。填写目标电脑实际服务地址（如 `http://目标IP:1234/v1`）与模型 ID；服务未启用认证时密钥环境变量名可留空，启用认证时填写对应变量名。本机 localhost 不代表另一台电脑。

ComfyUI 配置入口、集成目录和镜头数据契约已保留，当前视频提交明确禁用。获得已跑通的 API 工作流后再实现节点映射与执行核对，不编造节点、帧数和成功状态。

## 数据与恢复

默认 `data/studio.db` 为 SQLAlchemy/SQLite 业务数据，`data/checkpoints.db` 为 LangGraph 官方 SQLite 检查点。业务库仅通过 Alembic 迁移创建与升级。数据目录可用 `YINGZHANG_DATA_DIR` 设置为本地绝对路径；升级已有数据前备份，SQLite在线备份使用 `sqlite3.Connection.backup`，不能在写入时只复制主文件。

独立执行器使用数据库原子领取与租约心跳，多开执行器仍只领取一条运行。执行器失联且租约过期后转为 unknown，需人工核对后点击重试；最后一次未保存调用可能再次计费。暂停只在下一次模型调用前生效，当前调用会先保存结果。网络超时不自动重发，限流/暂时性服务错误在配置预算内重试。

原文按段落编号，长章节分段提取，再按场景拆镜和审核。上下文使用保守字符预算，并拒绝超限阶段，避免静默截断正文；极长单段或全章合并超限时需要增大实际支持的上下文预算或缩小章节。当前不实现无限长文本的递归压缩。
