# 映章 · 小说动漫工作台

依据 `../设计` 的业务方案、工程约束与绿白页面原型实现。第一版完成**章节 → 故事脚本（时长 · 分镜 · 动作 · 台词） → 视频提示词 → 镜头画面 → 文本预览/导出**，暂不提交视频任务。

## 安装与启动

要求 Python 3.11、uv。环境独立于 ComfyUI。

在项目目录执行：

```bash
cd 你的项目目录
uv sync --frozen
uv run python start.py
```

Windows PowerShell：

```powershell
cd 你的项目目录
uv sync --frozen
uv run python start.py
```

在运行 `start.py` 的那台电脑上打开 http://127.0.0.1:8501 。启动器先执行 Alembic 迁移，再启动一个独立文本执行器与当前网页界面。页面刷新不会重复启动执行器。退出启动器会停止子进程。依赖仅在显式安装时获取，不在运行时自动安装。

从另一台电脑打开云端工作台时，浏览器地址是 http://124.223.189.242:8501 。步骤见 [CLOUD.md](CLOUD.md)。

启动后进入「模型配置」的「文本模型配置」，填写 API 地址、模型名称和 API Key，然后保存。文本模型用于把章节原文生成为故事脚本。提示词在「提示词配置」中修改，只作用于之后新提交的任务。支持 OpenAI 兼容 Chat Completions。

「生图模型配置」可选择 OpenAI 兼容图片生成 API，或本机 FLUX.2（mflux）。本机模式填写 `mflux-generate-flux2` 可执行文件路径、模型 ID 与基础模型，不需要 API Key；默认预填当前 FLUX.2-klein-4B Q8 下载位置。生成时使用 1024×1024、4 步和低内存模式，超时可按本机速度调整。保存后进入「图像创作」，点击小说封面，选择章节与分镜，生成 1–4 张镜头候选图；采用后作为该镜头的参考画面展示在总览。OpenAI 兼容服务须返回 Base64 PNG/JPEG；URL 响应当前不支持。

模型配置通过顶部横向分页切换生图和文本模型。提示词配置同样分为「图像创作配置」「故事脚本配置」「视频制作配置」三页，分别保存。图像创作配置统一维护图片风格、应用场景、构图偏好和画面限制，人物、环境与镜头描述由故事脚本单独提供。生成前可查看最终提示词并填写本次补充要求。已保存的自定义配置保留。故事脚本只有一步：上传章节后直接生成脚本，不再有分析、大纲、分镜、复核四步。视频制作配置的这段文字作为「风格与限制」拼进每段视频提示词，画面与动作仍来自分镜；视频生成服务尚未接入。

「总览」位于「故事脚本」上方，展示同一作品封面库。打开作品后按章节查看分镜、参考图、视频三列，分镜来自本章最近一版已生成脚本的执行结果。参考图展示图像创作中已采用的镜头画面，也保留已关联的角色参考图；尚无采用画面时显示待生成。视频列显示该镜所属的视频组、组时长与所在分段帧数，提示词在「视频制作」页；仍未提交任何视频任务，所以不会出现成片。

「图像创作」与「视频制作」都以只读小说封面库作为入口，作品管理在「故事脚本」中进行。图像工作台按章节、镜头组织；人物与场景描述直接取自该版故事脚本的分镜行。图片保存实际提示词、模型及镜头内容指纹，脚本变化后旧图片不会自动绑定到新版。视频工作台只读分镜并编译提示词：选章节后按目标时长分组，展示每组提示词、分段帧数与工作流参数，可按需调整目标时长、单组上限和画幅并即时重编译，不创建视频任务、不连接 ComfyUI。新增数据表通过启动时的 Alembic `0003`、`0004` 迁移创建。

密钥从模型配置写入执行器可读的存储，不写入检查点、日志或导出。修改已保存的密钥后，下一次任务使用新配置。`.env.example` 是说明示例，应用不自动加载 `.env`。

## 使用

1. 在首页新建作品，进入「章节原文」粘贴章节，填写可选前情，保存章节。
2. 保存后直接点击「开始生成故事脚本」。执行器按段落顺序分批生成，每批完成即保存；章节较长时会在段落边界暂停，继续时不重复已保存的镜头。
3. 「故事脚本」页按 **编号 · 时长 · 分镜 · 动作 · 台词** 展示结果。分镜列写成「景别 · 运镜 · 画面描述」，景别固定为远景、全景、中景、近景、特写。可展开编辑器修改单行后保存为新版本，旧版本归档保留。
4. 「视频提示词」页把同一章分镜按目标时长（默认 15 秒）合并成组，编译成 ComfyUI 可直接粘贴的提示词与参数：每组的整段提示词、分段帧数、首帧来源、Wan2.2 TI2V-5B 的分辨率/采样/模型文件名与负面提示词都列在页面上，可逐段复制。页面下半部分可改目标时长、单组上限与画幅（16:9 / 9:16 / 1:1），保存后立即按新参数重新编译。
5. 页面右侧「生成进度」显示当前阶段、失败原因，并可暂停、继续或重试；旧版 Streamlit 界面另设「文本任务」页做同样的事。失败重试只补做未完成部分。
6. 将采用的角色视觉资料存入当前作品，后续章节复用。已创建运行保存资料快照，不自动替换旧脚本；修改资料后需有意创建新运行采用新版本。

镜头数按剧情决定，无固定章级时长；5秒为分镜设计参考，不是已适配视频模型的保证。单行超过 15 秒会提示拆分。视频组时长不固定：相邻分镜凑到目标时长即收组，放不下一个整镜就整镜并入（例如 13 秒 + 6 秒合为 19 秒），绝不把一镜拆到两个视频里；因此组时长允许超出目标。单段最多 121 帧（24 fps 下约 5 秒），更长的组按段生成、以上一段末帧续写，不做静默截断。合并逻辑与帧数换算不依赖 ComfyUI，也不创建视频任务。台词/文字叠加需求单独展示，不承诺声音和字幕产物。脚本校验没有发现问题也不能保证剧情完全准确，需人工阅读效果。

## 本地模型与 ComfyUI

LM Studio 使用相同模型配置和数据契约。填写目标电脑实际服务地址（如 `http://目标IP:1234/v1`）与模型 ID；服务未启用认证时密钥环境变量名可留空，启用认证时填写对应变量名。本机 localhost 不代表另一台电脑。

ComfyUI 配置入口、集成目录和镜头数据契约已保留，当前视频提交明确禁用。「视频提示词」页按 [ComfyUI 官方 Wan2.2 示例](https://comfyanonymous.github.io/ComfyUI_examples/wan22/) 与本机 5B 工作流编译参数：`image_to_video_wan22_5B.json`，1280×704（竖版 704×1280），24 fps，`length` 取 4n+1，`KSampler` 30 步、cfg 5、`uni_pc`/`simple`，`ModelSamplingSD3` shift 8，模型 `wan2.2_ti2v_5B_fp16.safetensors` + `umt5_xxl_fp8_e4m3fn_scaled.safetensors` + `wan2.2_vae.safetensors`，输出 `SaveWEBM`（vp9，24 fps）。提示词写法参考 [Wan2.2 文档](https://docs.comfy.org/tutorials/video/wan/wan2-2)。获得已跑通的 API 工作流后再实现节点映射与执行核对，不编造节点、帧数和成功状态。

## 数据与恢复

默认 `data/studio.db` 为 SQLAlchemy/SQLite 业务数据，`data/checkpoints.db` 为 LangGraph 官方 SQLite 检查点。业务库仅通过 Alembic 迁移创建与升级。数据目录可用 `YINGZHANG_DATA_DIR` 设置为本地绝对路径；升级已有数据前备份，SQLite在线备份使用 `sqlite3.Connection.backup`，不能在写入时只复制主文件。

独立执行器使用数据库原子领取与租约心跳，多开执行器仍只领取一条运行。执行器失联且租约过期后转为 unknown，需人工核对后点击重试；最后一次未保存调用可能再次计费。暂停只在下一次模型调用前生效，当前调用会先保存结果。网络超时不自动重发，限流/暂时性服务错误在配置预算内重试。

原文按段落编号，长章节分段提取，逐批生成脚本并在每批后保存。上下文使用保守字符预算，并拒绝超限请求，避免静默截断正文；极长单段或全章合并超限时需要增大实际支持的上下文预算或缩小章节。当前不实现无限长文本的递归压缩。

脚本校验是确定性的：检查镜头编号与顺序、角色引用与外观、原文段落覆盖、单镜时长上限，结果以「待核实」条目展示，不代表剧情已经正确。
