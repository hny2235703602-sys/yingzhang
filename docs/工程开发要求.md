# 小说转动漫工作流工程开发要求

> 状态：开发规范，尚未实现或验证运行环境。
> 适用范围：本地 Windows 单用户应用，优先连接线上语言模型 API，保留 LM Studio，视频通过 ComfyUI 执行。
> 来源：用户提供的《可复用工程开发要求》，按本项目规模和业务裁剪；本文是适用于本项目的规则，不全量继承原文模板。

## 1. 项目范围与技术基线

当前目标：输入小说章节，提取本章上下文，改编为动漫分镜与提示词，再生成独立镜头视频。镜头数量由剧情决定，不设置固定章级时长。跨章节只优先复用角色视觉资料；完整人物关系记忆库不属于第一版。

技术选择：Python 3.11、Streamlit、LangGraph、Pydantic 2、pydantic-settings、OpenAI Python SDK（兼容协议）、必要的原生协议适配、HTTPX、WebSocket 客户端、SQLite。SQLite 持久化访问采用 SQLAlchemy 2，结构迁移采用 Alembic；LangGraph 检查点使用其适配的持久化实现，不能手改框架内部表。依赖兼容性须在独立 Python 环境实测后锁定。

开发检查采用 Ruff（行宽 100）、mypy 和 pytest。保留现有 Python 版本选择，不因模板建议擅自升级。直接依赖在项目清单声明，用锁文件记录可复现版本；禁止运行时自动安装依赖。

不引入 FastAPI、React、Redis、Celery、MySQL、账户权限系统、图数据库或向量数据库。未来有明确需求时再评估。应用依赖与 ComfyUI 的 Python 环境分离，避免破坏已跑通的视频环境。

## 2. 分层与唯一规则来源

建议目录（尚未创建）：

```text
src/novel_anime/
  ui/                    # Streamlit 页面与交互
  application/           # 改编、编辑、提交、恢复等用例
  domain/                # 数据契约、状态流转、校验和失效规则
  workflows/             # LangGraph 图、节点与检查点衔接
  integrations/
    language_models/     # 统一接口、线上协议与 LM Studio 适配
    comfyui/             # 模板映射、提交、查询、事件适配
  persistence/           # 业务数据访问与事务
  workers/               # 独立本地任务执行器
  core/                  # 配置、日志与通用异常
prompts/                 # 按阶段版本化的提示词模板
migrations/              # 业务库迁移
tests/                   # 关键规则、恢复和适配器测试
```

界面调用应用服务，应用服务调用领域规则、数据访问和集成适配器。领域规则不依赖 Streamlit、HTTP 请求或数据库会话；工作流节点调用已有用例，不复制同一业务规则。

界面脚本刷新不得重复创建执行器或自动提交任务。长任务由独立本地执行进程处理，通过数据库读取任务；Streamlit 只创建任务和展示状态。默认单执行器，Qwen 与视频阶段串行使用资源，不引入分布式队列。

同一规则只有一个可信实现。按稳定重复需求再提取公共能力，不为未来多模型、多用户提前搭建万能抽象。

## 3. 类型、契约与命名

Python 使用 snake_case，类与异常使用 PascalCase，常量使用 UPPER_SNAKE_CASE。公开函数有参数与返回类型；业务数据用明确模型，不以任意字典贯穿所有层。

关键对象统一命名：Work、Chapter、SourceParagraph、StoryEvent、Scene、Shot、VisualProfile、GenerationProfile、GenerationTask。中文术语定义以项目领域词汇表为准，避免同一概念重复命名。

Pydantic 模型约束字段类型、长度、枚举与引用格式。分镜、生成请求、原始模型输出与数据库对象分开，执行前完成转换和校验。Schema 版本、提示词模板版本与工作流模板版本显式记录。

注释解释原因，重点说明状态、事务、重试、协议兼容和临时处理。公开服务方法写摘要、参数、返回与可能异常，避免重复类型定义或为显然代码堆注释。

## 4. 状态、幂等与恢复

章节分析、分镜校验和视频生成分别保存状态，不能用一个 completed 表示整个项目。合法状态流转集中定义，状态变化与对应本地记录在同一事务提交。

生成任务建议区分：pending、submitting、queued、running、succeeded、failed、unknown、cancel_requested、cancelled。unknown 表示远端是否接受或执行无法确认，不代表失败。取消请求也不代表已经取消成功。

每个任务保存作品、章节、镜头、镜头版本、生成配置、种子、工作流模板版本、输入摘要、执行尝试 ID 和远端 prompt_id。

- 网络重试复用同一尝试，稳定提交键防止用户双击或执行器重启重复建任务。
- 用户明确选择重做时创建新的执行尝试，保留旧结果；不能仅因参数相同就阻止有意重做。
- 相同幂等键且相同请求返回已有任务；相同键不同请求报告冲突。
- 提交前先持久化 submitting 状态。远端返回后保存 prompt_id，再更新排队状态。
- 接受请求但响应丢失时，进入 unknown，查询远端队列和历史；能验证时使用尝试标识关联。不能确认时暂停该尝试并提供核对入口，不盲目重新提交。
- 本地唯一约束不能保证远端恰好执行一次，不宣称具有该保证。
- WebSocket 断开不等于任务失败，重新连接后通过队列与历史核对。
- 成功须确认远端执行成功及预期输出信息，不能仅因收到进度结束或网络响应就标记成功。

默认只管理本应用创建的任务。取消时优先处理指定待执行任务；ComfyUI 的全局中断可能影响其他任务，不能直接把它当作单任务取消，也不自动清空整个队列。

## 5. 事务、并发与数据结构

应用服务划定短事务，不在事务内等待语言模型或视频 HTTP 请求。持久化状态推进与外部执行分步衔接，记录可恢复的中间状态。

SQLite 启用 foreign_keys，并为本项目同库稳定关系建立必要外键；不照搬模板的默认禁用物理外键约定。唯一约束保护幂等、编号和版本。采用 WAL、合理 busy_timeout 与短写事务；WAL 数据库存放在本地磁盘，不放网络共享目录。

单执行器使用数据库原子领取与运行租约防重复执行；进程失联后核对远端任务，再决定是否重新领取。不要只用 Python 内存变量保护任务。可编辑对象使用版本号检测并发覆盖，追加日志不强制使用版本锁。

可检索和约束的字段独立建列。JSON 适合版本化阶段结果、原始返回和不可变快照。未知值用 NULL，不以空字符串或伪造时间替代。

业务表结构变更使用经过审查的 Alembic 迁移，升级前备份，不能以启动时 create_all 替代后续迁移。LangGraph 检查点与业务库按各自迁移机制管理。

运行时间存储为 UTC，显示时转换本地时区；故事发生顺序使用独立的章节、场景、镜头位置，不用真实时间戳表达剧情顺序。

## 6. 版本、缓存与文件

原文、可选前情、角色视觉资料、提示词模板、模型配置、分镜与 ComfyUI 模板均记录版本或 SHA-256 摘要。缓存键包含所有直接影响结果的输入及阶段版本，不只按章节标题命中。

修改单镜提示词只使对应任务结果待更新；修改角色资料影响引用该版本的镜头；修改章节正文影响相关阶段及下游结果。不无条件重跑整个项目，也不把旧结果默认为最新版本成功结果。

输出使用稳定 ID 和执行尝试 ID 组织，标题只作为展示名；重做不覆盖旧文件。文件元数据与引用集中管理，本地写入采用临时文件加原子替换，避免中断留下半份 JSON。

备份业务数据库、角色素材和导出文件，检查点按所用实现备份；SQLite 在线备份使用受支持备份方式，不在 WAL 写入中仅复制单个数据库文件。删除项目或清理素材时检查引用和范围，禁止按未经确认的计算路径递归删除。

## 7. 线上语言模型、LM Studio 与 ComfyUI 适配

所有外部返回先验证，未知状态保留并报告。适配器统一处理协议、超时、错误分类、进度和内外 ID 映射；业务层不散布接口细节。

语言模型：优先使用线上 API Key 配置，保留本地 LM Studio；验证服务可达、协议、模型标识和实际输出能力；分开处理推理内容和结构化最终结果。输出截断、非法 JSON、无效引用、剧情缺口分别处理；只返修相关部分，次数有上限。结构校验通过不代表剧情语义正确。

ComfyUI：采用已跑通的 API 工作流模板；执行前检查节点字段、模型与必要素材、时长到帧数的映射。时长公式与帧数约束来自实际模型，不硬编码通用规则。资源释放同样通过已验证接口或可执行配置实现，不能只在文本里声称已卸载。

重试分层：连接失败等短暂错误允许有限退避并加抖动；缺模型、缺节点、无效配置、输出不支持不自动重复提交。显存不足暂停并保留诊断，降分辨率等改变生成结果的调整须记录为新配置，不能静默修改。

连接/读取请求、进度失联和整个任务执行分别设置超时策略。视频可运行数十分钟，不能复用普通短请求超时；监测超时先核对远端状态，不能直接把长视频任务重新排队。

## 8. 配置、输入与日志

配置通过 Pydantic Settings 统一读取，提供无密钥的环境示例。接口地址、输出目录、模型标识、上下文预算、超时、返修次数和生成参数可配置。真实凭证不写入源码、导出包或版本库。

默认仅本机访问界面。访问另一台 Windows 电脑时显式配置目标地址；当前开发电脑的 localhost 不能代表目标电脑。局域网暴露服务时单独配置访问边界，不默认绑定所有网卡。

正文和模型回复视为数据，不允许其中的文字改变系统指令、执行命令或选择任意文件路径。导入文件校验大小、类型和路径；输出约束在配置目录内，兼容 Windows 中文路径、保留字符和长文件名。

日志包含 UTC 时间、级别、阶段、work_id、chapter_id、shot_id、run_id、attempt_id 和 prompt_id（适用时）。默认不记录全文小说、完整提示词、凭证或完整模型原始回复；诊断数据按需保存并有清理策略。

错误使用稳定 code、用户可读 message 和关联 ID。界面解释失败阶段、影响范围与可采取操作；详细堆栈仅进诊断日志。禁止捕获异常后返回假成功或只写日志而不更新任务状态。

## 9. 界面规则

显示当前阶段、已完成数量、失败镜头和最后状态更新时间。准备、执行、空结果、错误和待核实分别显示，状态不能仅靠颜色表达。

输入和已编辑分镜在失败或刷新后可恢复。避免重复提交；暂停停止新任务派发，恢复后继续未完成工作。远端运行中任务的取消结果需单独确认。

展示镜头数量与粗估耗时，不强制新增审批步骤。仅在会覆盖或删除已有成果等确有破坏性的操作前确认。日志与界面不暴露底层异常细节。

分镜列表支持按场景筛选和分页，避免大量镜头一次渲染拖慢界面。Streamlit 第一版使用其主题和基础组件，不移植 React、Ant Design 的专属布局规则。

## 10. 验证与完成标准

文档变更检查范围与一致性即可；不为静态内容编写无价值测试。代码实施时重点使用 pytest 覆盖：

- Schema、原文引用、镜头唯一性和依赖校验。
- 状态合法流转、重复提交和有意重做的区别。
- 远端已接受但本地未保存响应、重启、断线、租约恢复。
- 事务回滚、版本冲突、缓存失效和单镜头重试。
- LM Studio 输出截断、非法 JSON、有限返修与错误映射。
- ComfyUI 排队、运行、失败、未知状态和输出核对。
- 文件写入中断、路径边界与 Windows 中文路径。

自动测试模拟外部服务，不默认调用真实模型生成视频。真实目标电脑测试单独执行，记录模型、工作流、配置、耗时和结果；至少验证文本闭环、代表性少量镜头及断点恢复。

Ruff、mypy 和相关测试须真实运行后才能报告通过。真实模型未连接、Windows 未验证、视频未生成时明确说明，不把示例数据或协议模拟当作端到端成功。

## 11. 文档维护与复用边界

设计方案保存业务流程，本文保存工程约束，领域词汇表只保存术语定义。公开类型和函数签名是接口细节来源，不在多份文档重复维护参数表。

重要集成模块实现时补充简短对接文档：职责边界、公开入口和约束。环境配置变化同步示例配置，模型协议变化同步适配说明，完成情况与计划明确区分。

从通用模板保留：分层、显式类型、配置集中、可恢复任务、幂等、短事务、唯一约束、错误分类、版本化、日志脱敏和风险测试。

不采用或调整：企业认证与权限、金额币种规则、React 前端栈、Celery/Redis、MySQL 类型和字符集、默认无物理外键、每新增函数必须测试等与本项目规模或数据库不匹配的要求。

## 12. 线上语言模型接入补充

线上 API 是当前优先路径，LM Studio 本地推理能力保留。统一模型接口与配置负责切换，业务流程不绑定提供商；视频生成仍走 ComfyUI，不默认增加线上视频接口。

每个配置记录 provider、protocol、base_url、model、密钥环境变量名称、上下文与输出预算、能力标记、超时、并发及重试上限。真实密钥只在执行时读取，不进入数据库、检查点、导出文件或日志。当前仅需环境变量配置，不新增企业密钥管理系统。

兼容协议通过 OpenAI SDK 调用，厂商原生协议按实际文档适配；不假设列出的模型支持结构化输出、推理控制或全部采样参数。SDK 与应用层共用有限重试预算，遵守服务端限流信息。认证、余额及配置错误不反复重试。

每次调用记录阶段、profile、实际模型、请求 ID、结束原因、耗时及供应商返回的用量，不默认记录正文。超时重试可能重复计费，无法确认用量时记为未知。成本有有效定价才估算；预算限制可选，触及时停止后续调用。

提供商、协议、模型、模板与参数参与缓存键。切换模型显式产生新运行版本；不自动跨提供商或回退本地，不静默覆盖已通过结果。线上无需执行本地模型卸载。

测试补充：401/403、余额不足、429/Retry-After、5xx、超时、截断、拒绝、结构化输出不支持、重试预算、敏感字段脱敏和跨配置缓存隔离。模拟测试不能当作真实模型已接通的证据。
